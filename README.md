# Лабораторная работа 2: APB-устройство "XOR с накоплением" (вариант 10)

Автор: Тищенко Арина Кареновна
Группа: М3О-409Б-23

## Описание проекта
Функциональное описание на SystemVerilog устройства с интерфейсом APB, выполняющего
сложение по модулю 2 (XOR) с накоплением. Устройство тестируется APB-мастером из Л/Р 1,
определяется кодовое покрытие.

## Регистры устройства
| Смещение | Регистр | Доступ | Назначение |
|----------|---------|--------|-----------|
| 0x00 | ADDEND | RW | добавляемое значение (32 бита) |
| 0x04 | CTRL | RW | бит 0 EN - разрешение накопления; бит 1 ADD - импульс `RESULT = RESULT ^ ADDEND` (при EN = 1); бит 2 CLR - импульс `RESULT = 0`       (приоритетнее ADD). ADD и CLR читаются как 0 |
| 0x08 | RESULT | RO | текущий результат; запись -> `pslverr = 1` |

Любой другой адрес -> `pslverr = 1`. Адрес декодируется по `paddr[7:0]`.

## Состав
- `apb_master.sv` - APB-мастер из Л/Р 1 (задачи `apb_write`, `apb_read`, `apb_read_check`) и тест.
- `apb_xor_acc.sv` - проверяемое устройство (APB slave с XOR-накоплением).
